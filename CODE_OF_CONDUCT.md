# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, be patient, and talk about the work, not the person. No harassment, no insults, no personal attacks, and nobody's private information without their permission.

To report a problem, use a private report at
https://github.com/esoteric-frog/nasty3ds/security/advisories/new and write "conduct" in the title. Reports stay private. The maintainer can remove comments, close threads, and block people who do not follow these rules.
